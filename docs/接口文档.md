# 外卖系统 · 接口文档

> 后端 context-path = `/api`，端口 `8080`。下表所有路径均已省略 `/api` 前缀。
> 前端开发时 Vite 代理 `/api` → `http://localhost:8080`（**不要 rewrite**，后端自身带 `/api` 前缀）。

## 一、通用约定

### 1.1 统一响应体

```json
{ "code": 200, "msg": "操作成功", "data": {} }
```

- `code = 200` 表示成功，其余为业务错误码，`msg` 可直接弹窗提示。
- 分页接口 `data` 为 `{ list: [], total: 0, pageNum: 1, pageSize: 10 }`。

### 1.2 双 token 错误码（前端必须特殊处理）

> **重要**：`accessToken` 过期时，后端返回的是 **HTTP 状态码 401 + 响应体 `code = 40101`**。
> 也就是说业务码在**响应体里**，不在 HTTP 状态码上。
> 前端如果在 axios 的 `error` 分支里「一见 401 就跳登录页」，自动续期将永远不会触发。
> 正确顺序：**先读 `error.response.data.code`**，是 40101 就走续期，其余 401 才登出。

| code      | HTTP 状态 | 含义                                        | 前端动作                                              |
| --------- | --------- | ------------------------------------------- | ----------------------------------------------------- |
| **40101** | 401       | accessToken 已过期                          | **静默调用 `/auth/refresh` 换新令牌，然后重放原请求** |
| **40102** | 401       | refreshToken 已失效                         | 清空登录态 → 跳登录页                                 |
| 401       | 401       | 未认证 / 令牌非法 / 令牌已进黑名单          | 清空登录态 → 跳登录页                                 |
| 403       | 200       | 已登录但无权访问（跨端调用 / 越权操作数据） | 只提示，**不要跳登录页**                              |

### 1.3 认证方式

请求头 `Authorization: Bearer {accessToken}`。

登录成功后返回：

```json
{
  "accessToken": "...",
  "refreshToken": "...",
  "tokenType": "Bearer",
  "expiresIn": 1800
}
```

### 1.4 端标识（登录必填）

`clientType` 取值 `CUSTOMER` / `MERCHANT` / `ADMIN`，必须与账号身份一致，否则返回 `10001 用户名或密码错误`。

| 端       | 账号                  | 密码   |
| -------- | --------------------- | ------ |
| 顾客端   | customer1             | 123456 |
| 商家端   | merchant1 / merchant2 | 123456 |
| 管理后台 | admin                 | 123456 |

## 二、认证接口 `/auth`

| 方法 | 路径       | 入参                                | 返回                                                           |
| ---- | ---------- | ----------------------------------- | -------------------------------------------------------------- |
| POST | `/login`   | `{username, password, clientType}`  | TokenVO                                                        |
| POST | `/refresh` | `{refreshToken}`                    | TokenVO（旧 refresh 立即作废）                                 |
| POST | `/logout`  | `{refreshToken?}`，需带 accessToken | Void                                                           |
| GET  | `/me`      | —                                   | `{userId, username, nickname, avatar, userType, userTypeDesc}` |

> 登录失败累计 5 次锁定 10 分钟（`15004`）；登录接口按 IP 限流 10 次/分钟（`15003`）。

### 3.4 购物车 `/customer/cart`

### 3.6 订单 `/customer/order`

| 方法 | 路径            | 入参                                               | 返回                            |

| POST | ``              | `{addressId, remark?, items:[{dishId, quantity}]}` | `{orderId, orderNo, payAmount}` |

## 六、通用接口

| 方法 | 路径           | 入参                                 | 返回                |
| ---- | -------------- | ------------------------------------ | ------------------- |
| POST | `/file/upload` | `multipart/form-data`，字段名 `file` | `{url, name, size}` |

- 限制：jpg/jpeg/png/gif/webp，单文件 ≤ 5MB。
- 返回的 `url` 形如 `/upload/2026/09/24/xxx.jpg`，**展示时需拼上 `/api` 前缀**（即 `/api/upload/...`）。

## 七、数据结构速查

**MerchantVO**：`id, name, logo, description, phone, address, minAmount, deliveryFee, businessStatus, businessStatusDesc, auditStatus, auditStatusDesc, auditRemark, rating, sales, ownerUserId, ownerUsername, createTime`

**DishVO**：`id, categoryId, categoryName, merchantId, name, image, description, price, stock, sales, status, statusDesc, createTime`

**DishGroupVO**：`{ categoryId, categoryName, dishes: DishVO[] }`

**CartItemVO**：`id, dishId, dishName, dishImage, price, quantity, amount, stock, available`

**CartShopGroupVO**：`{ merchantId, merchantName, merchantLogo, businessStatus, minAmount, deliveryFee, totalAmount, totalQuantity, reachMinAmount, items: CartItemVO[] }`

**AddressVO**：`id, receiver, phone, province, city, district, detail, label, isDefault, fullAddress`

**OrderVO**：`id, orderNo, userId, merchantId, merchantName, receiver, receiverPhone, receiverAddress, totalAmount, deliveryFee, payAmount, status, statusDesc, remark, cancelReason, payTime, acceptTime, finishTime, cancelTime, createTime, itemCount, items: OrderItemVO[]`

**OrderItemVO**：`dishId, dishName, dishImage, price, quantity, amount`

**OrderDetailVO**：`{ order: OrderVO, statusLogs: OrderStatusLogVO[] }`

**OrderStatusLogVO**：`fromStatus, fromStatusDesc, toStatus, toStatusDesc, operatorType, operatorTypeDesc, remark, createTime`

**PaymentVO**：`id, payNo, orderId, amount, payType, payTypeDesc, status, statusDesc, tradeNo, payTime`

**MerchantOverviewVO**：`merchantId, merchantName, businessStatus, todayOrderCount, todayAmount, monthOrderCount, monthAmount, pendingAcceptCount, pendingPaymentCount`

**PlatformOverviewVO**：`customerCount, merchantCount, pendingAuditCount, todayOrderCount, todayAmount, totalOrderCount, totalAmount, canceledCount`

**UserVO**：`id, username, phone, nickname, avatar, userType, userTypeDesc, status, lastLoginTime, createTime`

## 九、关键错误码

| code                    | 含义                                                |
| ----------------------- | --------------------------------------------------- |
| 10001                   | 用户名或密码错误                                    |
| 10002                   | 账号已停用                                          |
| 10003 / 10004           | 账号已存在 / 手机号已注册                           |
| 11001 11002 11003       | 店铺不存在 / 未通过审核 / 休息中                    |
| 12003 12004 12005       | 菜品不存在 / 已下架 / 库存不足                      |
| 13005                   | 一个订单只能包含同一家店铺的菜品                    |
| 14001 14002 14003 14004 | 订单不存在 / 状态不允许 / 未达起送价 / 无权操作订单 |
| 15001 15002 15003 15004 | 重复提交 / 幂等处理中 / 请求过频 / 密码错误次数过多 |
